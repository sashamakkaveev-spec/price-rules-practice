# Price Rules Practice

Учебный консольный проект на C# для расчёта цены с помощью последовательности правил. Написан для практики интерфейсов, композиции, проверки аргументов и unit-тестирования.

## Технологии

- C#, .NET 8
- NUnit

## Как работает расчёт

Каждое правило реализует интерфейс `IPriceRule` с методом `Apply(decimal price)`:

- `PercentageDiscountRule` уменьшает цену на заданный процент от 0 до 100.
- `FixedDiscountRule` вычитает фиксированную сумму. Если скидка больше цены, возвращает ноль.
- `MinimumPriceRule` поднимает цену до заданного минимума, если она ниже него.

`PriceCalculator` применяет правила в порядке передачи. Каждое следующее правило получает результат предыдущего. При пустом наборе правил возвращается исходная цена. Отрицательная исходная цена вызывает исключение.

Порядок влияет на результат. Для цены 1000:

| Правила | Итоговая цена |
|---|---:|
| Скидка 10%, затем минимум 950 | 950 |
| Минимум 950, затем скидка 10% | 900 |

В текущем консольном примере выполняется расчёт:

```text
1000 → скидка 10% → 900 → скидка 100 → 800 → минимум 850 → 850
```

## Запуск

Нужен .NET 8 SDK. Выполняйте команды из корневой папки репозитория, где находится `PriceRulesPractice.sln`.

Запуск консольного примера:

```bash
dotnet run --project PriceRulesPractice/PriceRulesPractice.csproj
```

Ожидаемый вывод:

```text
850
```

Запуск тестов:

```bash
dotnet test PriceRulesPractice.sln
```

## Что проверяют тесты

- Обычную фиксированную скидку и скидку больше цены.
- Отрицательную сумму фиксированной скидки и отрицательную цену в этом правиле.
- Порядок применения процентной скидки и минимальной цены.
- Пустой набор правил, в том числе с отрицательной исходной ценой.

## Структура

- `PriceRulesPractice` — правила расчёта, калькулятор и консольный пример.
- `PriceRulesPractice.Tests` — тесты NUnit.

## SQL-практика — PostgreSQL

В папке `sql` находятся учебные скрипты для работы с товарами
и историей изменения цен:

- `01_schema.sql` — создание таблиц, первичных и внешнего ключей,
  ограничений для данных.
- `02_seed.sql` — добавление пяти товаров и трёх записей истории.
- `03_queries.sql` — выборки с фильтрацией, INNER JOIN, LEFT JOIN,
  GROUP BY и HAVING.

### Как выполнить

1. Создайте отдельную пустую базу PostgreSQL.
2. Откройте SQL-консоль этой базы, например в Rider.
3. Выполните `01_schema.sql`, затем `02_seed.sql`.
4. Если используется ручное управление транзакциями, выполните Commit.
5. Выполняйте запросы из `03_queries.sql` по одному.

SQL-скрипты выполняются отдельно от консольного приложения C#.
Приложение пока не подключается к базе данных.
